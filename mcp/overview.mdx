## Server endpoint

```json
{
  "mcpServers": {
    "convosphere-docs": {
      "command": "node",
      "args": ["/workspace/Docs-Convosphere-AI/mcp-server.js"]
    }
  }
}
```

## Available tools

- `list_navigation`
- `get_page`
- `search_docs`
- `find_endpoint`
